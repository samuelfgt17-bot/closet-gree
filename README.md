# Closet Gree

Página de links (link na bio) e página de vendas do Método Achados PRO.

- `index.html`: página de links
- `metodo-achados-pro.html`: página de vendas da mentoria

## Publicar no GitHub Pages

```bash
git init
git add .
git commit -m "Primeira versão do site"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
git push -u origin main
```

Depois, no GitHub: Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
